# site

Small static about page for Mimir. Plain HTML/CSS, no build step, no dependencies.

## Deploy

**Drag and drop:** go to [vercel.com/new](https://vercel.com/new), drag this `site/` folder onto the page. Done, no config needed.

**Or via git:** connect the `hasil7677/mimir` repo in the Vercel dashboard and set the project's root directory to `engine/site`.

## Local preview

Open `index.html` directly in a browser, or serve it:

```
python -m http.server 8000
```

then visit `http://localhost:8000`.
